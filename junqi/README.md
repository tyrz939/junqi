# Junqi (TypeScript)

Phaser 3.88 + Vite. Code-only art. Jane arrives in Castle on a Sunday train and does not know she is a witch. The 2020 GameMaker project stays in `../Junqi-Legacy-GM`.

Pair with `../SYSTEMS.md` (the bar) and `../WORLDGEN.md` (how the county grows).

```bash
cd junqi
npm install
npm run dev
```

## Loop

Title → Julie's stoop → dog → house (**Icebolt** in the kitchen) → cellar / mine / burial → snake.

After the snake the county still turns. Each later door is a small Zelda dungeon with one trick:

| Place | You see first | You learn | You come back for |
| --- | --- | --- | --- |
| Factory | A dead gate | Lever in the crates, then a lock-in on the line | Repair the shop wreck → pipes |
| School | A glass case in the hall | Push desks for the office key, detention in the east | Bell in the office opens the case you walked past |
| Butterfly forest | A chest in the water | **Grow** (east garden) makes a floor | North fight, then the amulet |
| Pipes | A chest in a lake | Drain lever in the dry west | Walk |

Start with melee and Repair. Icebolt is a kitchen learn. Fireball is in the burial garden. Grow is in the forest.

Six towns (Cross, Rivermill, Acreton, Kiln End, Boneford, Ridgegate). Town boards and doorstep NPCs hand out work. Empty lots and occupied houses. Eat a full kitchen. Night and mountain take heat; campfires give it back.
